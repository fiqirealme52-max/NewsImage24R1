# The World in One Day — 24 November 2026

A 29-story newspaper front page for 24 November 2026 — one day of world news, laid out as a single front page.

The entry ships as `entry.png` next to `main.ts`; running `main.ts` copies the image into the output directory and verifies the delivered copy is byte-identical to the source.
